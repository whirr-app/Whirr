# Contributing

Whirr does not accept pull requests. The public repository receives one squashed commit per
release, so there is no branch to target and no history to rebase onto.

Issues are welcome and are read. If you have found a bug, a good report with versions and steps is
the most useful thing you can send. If you have a fix in mind, describe it in the issue; it will be
implemented in the private tree and credited in the release notes.
