# Support

Whirr is developed by one person in their spare time. The fastest way to get help is a clear
issue.

- **Something is broken:** open a
  [bug report](../../issues/new?template=bug_report.yml).
- **Something is missing:** open a
  [feature request](../../issues/new?template=feature_request.yml).
- **A privacy or security concern:** see [docs/SECURITY.md](docs/SECURITY.md). If the concern
  should not be public, say so in a short issue and a private channel will be arranged.

Whirr talks only to the Audiobookshelf server you configure. Problems with the server itself, its
library scanning, or its metadata belong to the
[Audiobookshelf project](https://github.com/advplyr/audiobookshelf).
